# 行情引擎 · 阿里云部署指南

目标：在阿里云服务器上 7×24 运行横盘行情，手机打开 App 时 K 线自动续上，不再重置。
分工：**真实账本数据仍然只存在手机本地**，服务器只做行情模拟与记录。

---

## 一、开通服务器（用学生券，约 5 分钟）

1. 登录阿里云 → 顶部搜索「**轻量应用服务器**」（学生新用户常有 99 元/年活动；300 元抵扣券在「费用中心 → 券与授权」里能看到，下单时选「抵扣券」支付）。
2. 创建实例：
   - 地域：选离你近的（如**杭州/上海**）
   - 镜像：**Ubuntu 22.04**（或 24.04）
   - 套餐：**2核2G 最低配即可**（本引擎只吃几十 MB 内存）
3. 创建完成后进入实例详情 → **重置密码**（root 的 SSH 密码），记下来。
4. 防火墙/安全组放行端口：实例详情 → 防火墙 → 添加规则 → **TCP 8787**（行情引擎端口）。
   22 端口默认已放行（SSH 用）。
5. 记下实例的**公网 IP**。

> 300 元券大约够 2核2G 轻量服务器跑大半年到一年，具体看券面规则。

## 二、部署引擎（约 2 分钟）

方式 A：在 WorkBuddy 里把 `server/` 目录下两个文件发给我 + 服务器 IP/密码，我可以直接帮你部署。
方式 B：自己动手（电脑上有 ssh 即可）：

```bash
# 1. 上传两个文件（在电脑上执行，替换 IP）
scp "D:/workbuddyspace/2026-11-09-13-34-39/server/ledger-engine.py" root@<你的IP>:/root/
scp "D:/workbuddyspace/2026-11-09-13-34-39/server/setup.sh" root@<你的IP>:/root/

# 2. 登录服务器并一键部署
ssh root@<你的IP>
bash /root/setup.sh
```

脚本结束时屏幕会打印一串**行情令牌**（32 位十六进制），复制下来。

## 三、填进 App

手机打开人生账本 → 设置 → 「行情服务器」：

- 地址：`http://<你的公网IP>:8787`
- 令牌：部署脚本打印的那串

填完自动保存，几秒内图表就会续上服务器攒的行情。之后每次记账，App 会自动把新基准推给服务器。

## 四、验证

电脑浏览器打开 `http://<你的IP>:8787/health`，能看到各板块的 base/cur 即为正常。

## 五、日常维护

```bash
systemctl status ledger-engine    # 看运行状态
systemctl restart ledger-engine   # 重启
cat /opt/ledger-engine/token.txt  # 再看令牌
cat /opt/ledger-engine/data/state.json | head -c 300   # 看落盘数据
```

数据文件在 `/opt/ledger-engine/data/state.json`，每 30 秒自动落盘；删掉它重启引擎即从当前基准重新开始。

## 说明

- 服务器重启/重置后：1 秒 tick 会从当前基准重新生成（最近 2 小时的秒级数据有落盘，能恢复）；1 分钟 K 线保留 30 天。
- 手机离线期间记了账：打开 App 时会先显示服务器行情（围绕旧基准），随后自动跳变到你记账后的新值继续走——和真实行情跳空一致。
- 持仓板块不参与模拟（它走真实的股票/汇率行情同步）。
